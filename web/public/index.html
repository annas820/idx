The Indonesian stock market, from your terminal.

idx is one open-source binary for IDX / IHSG analysis. People get tables, scripts get stable JSON, and AI agents get the same capabilities as MCP tools. Free public data only, no API keys.

Install the CLI Source on GitHub Web terminal opens here with the first release.

Free data, no keys

Yahoo Finance today; MSN Money, idx.co.id and Indonesian finance news next. Every source sits behind a Provider trait, so one breaking does not take the tool down.

Built for agents

-o json emits a schema-documented envelope and exit codes mean something. idx mcp will expose every command as a typed MCP tool for Claude Code and friends.

Works offline

Responses are cached with per-endpoint TTLs. --offline serves the cache instead of failing when the network is gone.

Ownership, not just prices

Coming: KSEI monthly holder reports ingested into local SQLite, so you can ask who holds more than 1% of a ticker and how that changed month over month.

Install

Pre-built binaries, an install.sh with checksum verification and an npm wrapper arrive with the first tagged release. Until then, build from source with Rust:

cargo install --git https://github.com/fzn0x/idx
