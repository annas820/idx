KeteranganNotes

idx is one open-source binary for the Indonesia Stock Exchange: quotes, history, fundamentals, technicals, the KSEI register of holders above 1 %, news.

Three faces, one answer. A table for people, -o json for scripts, and idx mcp for Claude Code, Codex, Muse Code, Cursor and twenty other agents return the same fields. idx mcp setup <client> prints the registration for each; idx mcp --http serves URL-only products such as ChatGPT.

Free, no keys. Yahoo Finance, MSN Money, IDX and public feeds. Nothing is estimated; a field the source lacks is null.

CatatanNotes to the statements · what this tool does and does not do

Scope. stocks quote · history · profile · financials · earnings · dividends · returns · fundamental · technical · brief · compare · screen · news · sentiment, market overview, ownership import · ticker · entity · changes · foreign and watch, plus mcp, schema, config, cache. Output as a table, -o json or -o csv. Every command works on IDX tickers such as BBCA; ^JKSE is IHSG.

Sources. Yahoo Finance for prices, history, profiles, ratios, earnings and statements; MSN Money for a second opinion on ratios and analyst targets; IDX's monthly KSEI file for holders above 1 %; Kontan and CNBC Indonesia feeds for news. Every response names its provider, fetched_at, and whether it came from cache.

Provenance over polish. When two sources disagree they are never averaged: the first answers, the second fills blanks, and sources lists who contributed. Yahoo publishes gross margin as 0 for banks; idx publishes null, because it means not applicable.

Ownership. Since March 2026 KSEI compiles, and IDX publishes monthly, every holder above 1 % of a listed company. The CLI imports the XLSX (or the earlier PDF) into local SQLite with normalised entity names, so who holds more than 1 % of BBCA and what did this fund change last month are one command each. idx.co.id sits behind Cloudflare; the import explains the manual path when a download is refused.

Heuristics are labelled. The fundamentals verdict, the technical signal and the news sentiment are rule scores. Every rule that fired is listed in plain language, and none of them is advice.

Offline and free. Responses are cached with per-endpoint lifetimes; --offline serves the cache when the network is gone. No accounts, no keys, no paywall. MIT licence; self-hosting this page is one wrangler deploy.
