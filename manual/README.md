# manual/

Tempat Bos mengunggah data ringkasan saham harian yang diunduh sendiri dari idx.co.id
(server cloud diblokir Cloudflare, browser Bos tidak).

- Nama file: `stocksummary_YYYYMMDD.<ekstensi asli>` (contoh `stocksummary_20261027.xlsx`).
- Unggah setelah pasar tutup (sekitar 16:30 WIB ke atas).
- Format file belum dikunci. File contoh pertama menentukan cara bacanya; jangan diubah isinya.
- Data ini memberi jual-beli asing per saham, bukan akumulasi broker, jadi sinyalnya terpisah (v1.1).
